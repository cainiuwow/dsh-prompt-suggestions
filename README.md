# dsh-prompt-suggestions

**English.** A planned input-prediction and prompt-suggestion plugin for DeepSeek Harness (dsh). The host — terminal, editor, or another environment — is not chosen yet. This repository has no plugin implementation and no host integration.

## 这是什么

本仓库准备做 **DeepSeek Harness（dsh）** 的输入预测 / 提示建议插件：在用户输入过程中预测后续内容，并给出提示建议。

宿主还没定。终端、编辑器或其他环境都有可能，具体接在哪里留到后面再决定。目前没有任何宿主接入。
